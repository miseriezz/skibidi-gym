# SKIBIDI Gym Tracker (Персональное PWA для зала)

Ультра-быстрое локальное веб-приложение (PWA) для силовых тренировок в **SKIBIDI Fitness** в тёмной теме (**OLED Dark**), заточенное под работу одной рукой в зале на **Vivo X300 (Android 17, Chrome / Edge)**.

## Что реализовано

1. **Твоя программа и 4-недельный цикл (Пн / Ср / Пт):**
   - **Неделя 1:** Верх А → Низ → Верх Б
   - **Неделя 2:** Верх Б → Низ → Верх А
   - **Неделя 3:** Верх А → Низ → Верх Б
   - **Неделя 4 (Разгрузка):** автоматически убирает 1 подход из каждого упражнения (2 вместо 3) и снижает рабочие веса на ~18% (после недели разгрузки рабочие веса не теряются и возвращаются к прежним!).
2. **Круговой регулятор Matrix (`[ 0 | +2.3 | +4.6 ]`) — Вариант А:**
   - В каждом подходе на блочных и рычажных тренажёрах Matrix основная плитка вводится в поле веса, а довесок `+2.3 кг` или `+4.6 кг` переключается кнопкой рядом.
3. **Каскад веса между подходами и точная статистика:**
   - Перед 1-м подходом автоматически подставляется вес с предыдущей тренировки.
   - При изменении или завершении подхода его вес автоматически переходит на следующие ещё не выполненные подходы, но в историю записывается фактический вес каждого подхода (и отдельно фиксируется стартовый вес 1-го подхода).
4. **Быстрая смена снаряда прямо на тренировке:**
   - Нажми на плашку снаряда в карточке упражнения (`Matrix`, `Блок`, `Штанга 20 кг`, `2 Гантели Σ`, `1 Гантель / Блины`, `Свой вес`).
   - Для **Штанги (20 кг)** показывает расчёт блинов на каждую сторону.
   - Для **2 Гантелей** считает сумму двух гантелей (и подсказывает вес одной в руке).
   - Для **Подтягиваний** — учёт собственного веса на количество раз.
   - Для **Планки** — встроенный секундомер прямо в строке подхода (`1:35`).
5. **Настраиваемая разминка в начале тренировки:**
   - Чек-лист разминки (отдельно для дней Верх и Низ), который сворачивается по нажатию «Разминка выполнена ✓» и не засоряет силовую статистику.
6. **Фоновый таймер отдыха (60 сек по умолчанию):**
   - Работает через системные метки времени (`endTime - Date.now()`), не сбивается при блокировке экрана, поддерживает кнопки `-15с` / `+15с` и `Screen Wake Lock API`.
   - Полная тишина во время тренировки — мягкий сигнал и вибрация срабатывают **только в самом конце отдыха (`00:00`)** и не ставят музыку на паузу.
7. **Двойная защита базы данных (`0 ₽`):**
   - Локальная база **IndexedDB** (`navigator.storage.persist()`) + мгновенное зеркало активной тренировки в `localStorage` на случай перезагрузки телефона.
   - **Экспорт / Импорт JSON** + отправка бэкапа через системное меню «Поделиться» (например, в «Избранное» Telegram).
   - **Облачная синхронизация Supabase** (автоматическая выгрузка после каждой тренировки + восстановление в 1 клик).

## Как запустить прямо сейчас на ПК или телефоне

Запусти файл `start_local_server.bat` (или выполни в терминале `F:\Programs\Python3.9\python.exe -m http.server 8080`) и открой `http://localhost:8080`.

## Как бесплатно выложить в интернет (GitHub Pages за 1 минуту), чтобы установить PWA на главный экран Vivo X300

Так как приложение написано на чистых ES-модулях без сборщиков и внешних зависимостей:
1. Создай бесплатный репозиторий на GitHub и загрузи туда все файлы из папки `g:\FitnessAPP`.
2. В настройках репозитория открой **Settings → Pages → Branch: `main` → Save**.
3. Открой полученную `https://...github.io/...` ссылку в Chrome или Edge на своём **Vivo X300** и нажми **«Добавить на главный экран» (Установить приложение)**.
